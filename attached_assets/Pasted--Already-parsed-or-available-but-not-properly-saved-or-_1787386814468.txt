## Already parsed or available, but not properly saved or surfaced

These are relatively straightforward additions because data is already produced by the parser or current replay pipeline.

### Draft

- Complete pick/ban order
- Team resolving for each pick/ban
- Pick/ban phase
- Hero draft order
- Draft timing where available

The parser handles the draft, but it is not currently stored as a dedicated match record.

### Chat and communication

- Chat-wheel lines
- Potentially pause/unpause messages and system messages

This requires care: chat is personal/player content, so it should likely be opt-in, admin-only, or moderated rather than public by default.

### Better position data

- One-second player positions rather than the current sampled positions
- Position trails
- Lane routes
- Rotation paths
- Jungle pathing
- Heatmaps
- Death locations
- Fight locations
- Ward coverage maps

### Teamfights

- Structured teamfight blocks
- Fight start/end time
- Location
- Players involved
- Kills and deaths
- Damage and healing during the fight
- Net-worth swing
- Buybacks used
- Ultimate usage
- Winner of each fight
- “Fight participation” beyond the current aggregate count

### More detailed existing logs

- Full buyback timeline rather than only count/dieback
- Buyback timing, death-to-buyback delay, likely cost, and outcome
- Rune type breakdown rather than only total pickup count
- Exact TP timings instead of only TP count
- Full ward placement/death timeline
- Better smoke timeline and affected players
- Talent choices, talent timing, and final skill build
- Ability-level progression, not just a generic ability log
- Item history shown as a timeline rather than a simple purchase list

## Additional demo stats we could add with parser extensions

- Damage dealt by:
  - Hero
  - Ability
  - Item
  - Physical / magical / pure damage type
  - Target hero
  - Target building
- Damage received by source
- Healing by hero, ability, item, or ally
- Shielding / damage prevented where replay events expose it
- Damage during teamfights
- Burst damage windows, such as damage in three/five/ten seconds
- First damage in fights
- Kill securing versus assist contribution
- Disable-chain duration
- Silence, root, stun, hex, slow, and break uptime
- Debuff application and removal
- Ultimate hits, misses, and multi-target use
- Ability accuracy for trackable projectiles/skill shots

- Deaths before key objectives

- Farm efficiency by minute
- Efficiency of jungle pathing
- GPM versus available map space
- Fight attendance rate
- Objective attendance rate
- Support action rate: wards, dewards, saves, stacks, pulls
- Core action rate: CS, tower pressure, damage, objective conversion
- Net-worth lead conversion rate
- Throw/comeback detection

- Item timing versus bracket/hero benchmarks
- Player-versus-hero historical performance
- Hero-pair synergy and counter performance
- Role-specific benchmark percentiles
- Clutch metrics: saves, steals, base defences, comeback fights
