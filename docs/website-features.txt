TrueSkill MMR — conservative mu-3sigma estimate; 8-tier medieval ladder (Apprentice -> King)
Smurf detector — 0-100 from 5 signals incl. Shannon-entropy hero pools + device fingerprinting
Lootbox "truthful odds" — UI fetches the exact catalog the server rolls from
Anti-cheat minigames — HMAC image/audio proxying hides answers from the network tab
